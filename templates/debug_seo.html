2. API 使用建議

✅ 重要提示：

  • 使用中文關鍵字：DataForSEO API 針對香港地區，中文關鍵字效果最好
  • 避免冷門詞彙：過於專業或搜尋量低的關鍵字可能返回空數據
  • 建議測試關鍵字：長者、健康、護理、醫療服務、安老院
  • 英文關鍵字限制：在香港地區可能數據較少
📊 數據返回說明：

• Trends Topics/Queries: 0 → 該關鍵字在香港地區 Google Trends 數據不足
• 關鍵字指標未返回數據 → 該關鍵字搜尋量過低或不在 Google Ads 資料庫中
• SERP 有機結果 > 0 → 正常，表示 API 可以獲取搜尋結果
