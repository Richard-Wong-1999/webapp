2. API 使用建議

✅ 重要提示：

  • 使用中文關鍵字：DataForSEO API 針對香港地區，中文關鍵字效果最好
  • 避免冷門詞彙：過於專業或搜尋量低的關鍵字可能返回空數據
  • 建議測試關鍵字：長者、健康、護理、醫療服務、安老院
  • 英文關鍵字限制：在香港地區可能數據較少
  • 中文關鍵字建議較少：受 Google Ads 數據庫限制，中文關鍵字相關建議通常少於英文
📊 數據返回說明：

• Trends Topics/Queries: 0 → 該關鍵字在香港地區 Google Trends 數據不足（正常現象）
• 關鍵字建議只有 1 個 → 中文關鍵字在 Google Ads 相關建議較少（已啟用降級機制）
• SERP 有機結果 > 0 → 正常，表示 API 可以獲取搜尋結果

⚙️ 系統快取設定

為了提升查詢速度並降低 API 調用頻率，系統對 SEO 數據進行快取：

數據類型 快取時間 說明
Google Trends 1 小時 趨勢數據變化較快，每小時更新
關鍵字指標 24 小時 搜尋量、CPC 等數據較穩定，每天更新
SERP 結果 6 小時 搜尋結果排名每 6 小時更新一次

💡 提示：如果需要最新數據，可以在資料庫中手動清除快取，或等待快取自動過期。
